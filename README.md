# 🤖 AI Interview Agent — Smart Interview AI (MERN + Gemini TTS)

A **production-ready AI Mock Interview Platform** built using the MERN stack (MongoDB, Express.js, React.js, Node.js) and powered by **Google Gemini AI**. This application allows users to upload resumes, generate role-tailored interview questions, and conduct realistic voice-based mock interviews featuring human-like speech synthesis, synchronized avatars, and automated evaluation.

---

## 🚀 Key Features

### 🎙️ Human-like Voice Interview (Gemini Neural TTS)
* **Replaces Robotic Speech:** Uses Google's **Gemini Neural TTS** (`gemini-3.8-flash-tts` with `gemini-3.1-flash-tts-preview` fallback).
* **Authentic Personas:**
  - 👩 **Priya (Female):** Voice `Kore` — warm, conversational, friendly senior interviewer.
  - 👨 **Rahul (Male):** Voice `Puck` — relaxed, confident, natural cadence with conversational fillers.
* **Synchronized Video Avatars:** Male and female video avatars lip-sync/animate while the interviewer speaks and pause on a resting frame when listening.
* **Zero-Latency Prefetching:** The upcoming question's audio is prefetched in the background while the candidate answers.
* **Auto-Muting:** Candidate's microphone is muted during audio playback to prevent echo and false transcription.
* **Live Captions & Fallback:** Shows spoken subtitles with a graceful captions-only fallback and "Retry voice" button if rate-limited.

### 🔐 Authentication & Security
* Firebase Google Authentication with popup sign-in.
* Server-side signed JWTs stored in secure `HttpOnly`, `SameSite` cookies.
* Protected route guards for interview, history, and report views.

### 📄 Resume Analysis
* Upload resumes in PDF format (up to 5MB) via Multer.
* Text extraction using `pdfjs-dist`.
* Google Gemini AI extracts suggested roles, experience levels, projects, and skills to pre-populate interview setup.
* Resumes are cleaned up from disk immediately after extraction.

### 🧠 Intelligent Question Generation & Real-time Scoring
* 5 progressive questions (Easy ➡️ Medium ➡️ Hard) generated by `gemini-3.5-flash-lite`.
* Strict question time limits (60s, 90s, 120s) with animated countdown timer and auto-submission.
* 3-pillar evaluation on every answer: **Confidence**, **Communication**, and **Correctness** (0 to 10 scale).
* Instant verbal and written feedback after each question.

### 📊 Analytics & PDF Export
* Full post-interview dashboard featuring circular score progress, Recharts score trajectory curve, and question audit table.
* One-click downloadable publication-ready A4 PDF report generated via `jspdf` and `jspdf-autotable`.

### 💳 Credit System & Monetization
* Users start with 1,000 complimentary credits.
* Interviews cost 50 credits per session.
* Integrated with **Razorpay** for credit top-up packages with HMAC-SHA256 signature verification.

## ⚡ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smart-interview-AI.git
cd smart-interview-AI
```

### 2. Install dependencies

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

### 3. Setup environment variables

#### Backend (`server/.env`):
```env
PORT=3000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
GEMINI_TEXT_MODEL=gemini-3.5-flash-lite
GEMINI_TTS_MODEL=gemini-3.8-flash-tts
GEMINI_TTS_FALLBACK_MODEL=gemini-3.1-flash-tts-preview
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

#### Frontend (`client/.env`):
```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_BACKEND_URL=http://localhost:3000
VITE_RAZORPAY_KEY_ID=your_razorpay_key
```

### 4. Run the project

```bash
# Backend
cd server
npm run dev

# Frontend
cd ../client
npm run dev
```

## 💡 How It Works

1. User logs in with Google OAuth.
2. (Optional) Uploads resume PDF — AI extracts skills and projects.
3. Selects role, experience, mode (Technical/HR), and interviewer voice persona (Priya / Rahul).
4. AI generates 5 progressive questions and conducts the interview with realistic Gemini Neural TTS speech.
5. User answers via voice (STT) or typing; AI provides verbal feedback after each turn.
6. Detailed performance analytics and downloadable PDF reports are generated upon completion.
